# Project Armstrong

An expensive project, spearheaded by [Mami](https://tts.determinismsucks.net/wiki/Mami) and run by Vlad and Tao, to create an apparatus capable of long-distance wormholes, using a mixture of new technology and [Ryouko](https://tts.determinismsucks.net/wiki/Ryouko) and [Asami](https://tts.determinismsucks.net/wiki/Asami)'s powers. Aka 3d4a-626. Hoped to be used in repeated [jumpstrikes](https://tts.determinismsucks.net/wiki/Jumpstrikes) against targets deep in [Ceph](https://tts.determinismsucks.net/wiki/Ceph) space.
